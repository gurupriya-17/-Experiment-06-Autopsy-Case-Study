# Experiment 6: Solve a Case Study Using Autopsy

## Aim
To investigate a digital forensic case study image using Autopsy.

## Tool Used
- Autopsy

## Procedure
1. Open Autopsy and create a new case.
2. Enter the required case details.
3. Add the provided case study disk image as the data source.
4. Configure the data source settings.
5. Run the available ingest modules to analyze the image.
6. Examine the results, including files and other available digital evidence.
7. Record relevant findings from the investigation.
